## 🚀 How to Host for Free on GitHub Pages

You have two simple ways to publish this live on the web:

### Method A: As your Main Developer Website (`mohammedtahawy.github.io`) — ⭐ Recommended
1. Create a new repository on your GitHub account named:
   ```
   MohammedTahawy.github.io
   ```
2. Copy the contents of this `portfolio/` folder into the root of that new repository.
3. Commit and push:
   ```bash
   git add .
   git commit -m "Deploy Mohamed Tahawy AI Engineer Portfolio"
   git push origin main
   ```
4. Within 60 seconds, your portfolio will be live at:
   **`https://mohammedtahawy.github.io`**

---

### Method B: Directly inside your current `CV-editor` repository
1. Go to your repository settings on GitHub:
   `https://github.com/MohammedTahawy/CV-editor/settings/pages`
2. Under **Build and deployment** > **Source**, select `Deploy from a branch`.
3. Choose branch `main` and folder `/docs` or configure GitHub Actions to deploy the `portfolio` folder.
   *(Alternatively, create a branch named `gh-pages` with the contents of this folder)*.
